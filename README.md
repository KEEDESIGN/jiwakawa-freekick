# じわかわフリーキック ⚽

フリック操作で爽快シュート！じわかわなキャラクターたちとエンドレスに遊べるサッカーフリーキックWebゲーム。

## 🎮 特徴
- **スワイプ＆カーブシュート**: スワイプした軌道に沿ってボールが変化球のように曲がる直感的な操作感
- **壁のすり抜け演出**: 壁（オレンジの人型）がランダムに配置変更 & 約40%で股抜きやすり抜けが発生！
- **ゴール & ポスト判定**: 枠内ゴール判定およびポスト直撃（POST!）判定
- **内蔵Web Audio音響**: 外部ファイル不要のサウンドエフェクト
- **Firebase Hosting対応**: `https://townsnapdesignpeople.web.app/freekick/`

## 📁 ディレクトリ構造
- `public/index.html` - ゲームUI
- `public/style.css` - スタイル定義
- `public/game.js` - ゲームロジック & 物理シミュレーション
- `public/assets/` - イラスト素材（ボール、ゴール、キッカー、壁）
- `firebase.json` - Firebase Hosting設定
